密码迁移

换电脑时使用
导出文件用 PBKDF2-SHA256 + AES-256-GCM 加密，口令不落盘、不进日志。绝不放宽 DPAPI 到本机范围——那等于同机任何账号都能解开密文。口令请另走一个渠道告知。
为什么界面永远看不到已存密码？
配置与密文分开存放：config.json 可漫游但不含密文，secret.json 留在本机并用 DPAPI 加密。密文只对「同机 + 同账号」可解。若解不开（foreign），界面保留原密文原样写回，绝不因为「点一次保存」删掉别人的密码。
